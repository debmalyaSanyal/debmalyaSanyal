## 🚀 Featured Projects

### 📝 1. PaperAlpha — AI-Powered Research Paper Assistant

An AI-powered platform designed to help researchers with literature discovery, research material analysis, structured paper writing, quality checks, and document export.

- 🔎 Literature discovery using OpenAlex and Crossref.
- ✍️ Section-by-section research writing workflow.
- 📄 DOCX export and research quality checks.
- ⚛️ Built using Next.js, React, TypeScript, and Tailwind CSS.

### 🎙️ 2. Offline AI Meeting Assistant

A privacy-focused meeting transcription system that captures microphone and system audio and converts speech into text locally.

- Real-time audio capture.
- Local speech recognition using Faster-Whisper.
- GPU-accelerated inference with CUDA.
- No external transcription API required.

🔗 [Explore the Repository](https://github.com/debmalyaSanyal/REAL_Time_transcription)

### 🏥 3. OpenClinicalAI

A modular, FHIR-first clinical AI foundation designed around an API-first architecture and privacy-conscious healthcare workflows.

- FastAPI-based backend architecture.
- Modular and plugin-oriented design.
- Docker-based development support.
- Healthcare interoperability and PHI-safe principles.

🔗 [Explore the Repository](https://github.com/debmalyaSanyal/OpenClinicalAI)

### 🚌 4. Where Is My Bus?

A responsive web application prototype focused on helping users explore bus routes and estimated schedules in Kolkata.

- Bus route exploration.
- Estimated schedule and position information.
- Responsive interface.

*Note: This is a prototype and does not claim live GPS tracking.*

🔗 [Explore the Repository](https://github.com/debmalyaSanyal/WHERE-IS-MY-BUS)

### 🧩 5. LLM Quiz Generator

A web-based project exploring automated quiz generation using web content extraction and Hugging Face language models.

- Web scraping using Puppeteer and Cheerio.
- LLM-powered question generation.
- Node.js and Express backend.

🔗 [Explore the Repository](https://github.com/debmalyaSanyal/llm-quiz-project)
